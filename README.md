# Stack · Pitch

The pitch site for **Stack**, designed and built by Harrison Greener: the 3-minute pitch video, the animated pitch deck, and the live prototype in one page.

- **Prototype:** https://harrisongreener.github.io/stack/
- **Video:** put the compressed file at `assets/stack-pitch.mp4` (under 100MB) and it plays on the page automatically. Paste the unlisted YouTube link into `YT` near the top of the script in `index.html`.
- **Deck:** scroll through it, or press Present for full screen with the arrow keys. Download PDF uses the browser's print to PDF.

Figures in the three-year model are illustrative assumptions, not a forecast. Album artwork and audio belong to their artists and labels.
